4.1 Project Timeline

Approximately 275 hours in total. Phases overlap: the platform work in P4 runs alongside P3 so there is always something to progress when one side is blocked.

Phase Period Key tasks Deliverable Hours
P0 Setup Oct 2026 Apply for SoccerNet data access and ethics approval; set up repository, CI and development environment; assemble the existing YOLO, ByteTrack and Roboflow tools and get them running on one clip Existing tools working end to end, applications submitted 30
P1 Measuring the baseline Oct - Dec 2026 Measure how accurate the off-the-shelf player positions actually are against SoccerNet ground truth; test how accuracy degrades with camera angle, player crowding and occlusion; build the error model A measured accuracy figure and an error model 50
P2 Rules and uncertainty Nov 2026 - Jan 2027 Detect the frame the ball is kicked; build and unit-test the Law 11 rules engine, including the frontmost legally playable body part; propagate the error model into a margin with an error bar and a "too close to call" verdict Rules engine listing every offside-position attacker with honest margins 70
P3 Involvement Jan - Mar 2027 Track each offside player for about two seconds after the kick; extract movement features; describe what each one did Involvement description for each candidate 35
P4 Application Jan - Mar 2027 Build the web application: YouTube URL plus timestamp, file upload, and the comparison view; AWS backend (Lambda, API Gateway, DynamoDB, S3); CI/CD through to deployment; measure delivery delay Working web application, deployed 60
P5 Evaluation Mar - Apr 2027 Test against SoccerNet, published VAR reviews and my own footage; run the observer study; write the dissertation; prepare the demo Dissertation, results and demonstration 30
Total 275

4.2 Goals

The basic goals together make a complete project. Stretch goals are attempted in the order listed, only once the basics are working.

Type ID Goal
Off the shelf - Player, ball and referee detection (YOLO) - installed and used as-is, not my work
Off the shelf - Player tracking (ByteTrack), team assignment by kit colour, pose keypoints - used as-is
Off the shelf - Pitch-marking detection and top-down transform (Roboflow sports) - used as-is
Basic B1 A measured accuracy figure for the off-the-shelf player positions, against ground truth
Basic B2 An error model describing how that accuracy varies with camera angle, crowding and occlusion
Basic B3 Automatic detection of the frame on which the ball was kicked
Basic B4 Tested Law 11 rules engine listing every attacker in an offside position, not just the scorer
Basic B5 Margins reported with an error bar, and a "too close to call" verdict when the margin falls inside it
Basic B6 Web application that runs the full analysis from a YouTube URL plus timestamp, or from an uploaded file
Stretch S1 Comparison view showing two analyses side by side
Stretch S2 AWS deployment with live push to the application and measured delivery delay
Stretch S3 Telling a passive offside player apart from one actively going for the ball
Stretch S4 Authentication and a documented security review
Stretch S5 Load and performance testing under concurrent jobs
Stretch S6 Observer study comparing what people notice in a clip against what the system flags
Out of scope - Live TV stream integration (licensing) and multi-camera analysis (no suitable data)
